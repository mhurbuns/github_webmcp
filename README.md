# WebMCP Repository Playground — Context Pack

This pack contains the project context for bootstrapping a WebMCP experiment/competition project in Codex CLI.

## Files
- `AGENTS.md` — persistent instructions for Codex
- `docs/PRODUCT_BRIEF.md` — product scope and canonical demo
- `docs/WEBMCP_CONCEPT.md` — shared mental model and technology distinctions
- `docs/ARCHITECTURE.md` — milestone-1 technical architecture
- `docs/COMPETITION_PLAN.md` — competition strategy and scope discipline
- `FIRST_CODEX_PROMPT.md` — first prompt to give Codex

## Use
1. Create/open the new project repository.
2. Copy these files into its root, preserving the `docs/` folder.
3. Commit them before implementation so product/architecture decisions are versioned.
4. Start Codex CLI in the repo.
5. Paste the contents of `FIRST_CODEX_PROMPT.md`.
6. Review Codex's proposed plan before asking it to implement milestone 1.

Treat these docs as living project context. Update them when important decisions change.
